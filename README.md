# USV-Posture-Library

本项目包含用于**无人艇（USV）姿态预测与姿态分类预测**的相关代码，主要包括数据预处理、分类标签生成、模型训练、预测以及泛化性测试等功能。

## 1. 项目使用流程

### 最新版本：2025.12.10

如果已经准备好所需数据集和环境，可以直接运行：

```text
Classification/
└── roll predict classify(25.11.11).py
```

运行前请根据本地环境检查代码中的**数据集路径**和**模型权重路径**。

---

## 2. 完整使用流程

如果是首次使用本项目，建议按照以下步骤执行。

### Step 1：下载项目并安装依赖

下载整个项目后，在项目根目录下执行：

```bash
pip install -r requirements.txt
```

> 注意：文件名应为 `requirements.txt`。

---

### Step 2：制作分类标签数据集

运行：

```text
Classification/
└── data-pre-label.py
```

运行前需要修改代码中的**原始 CSV 数据集路径**。

该程序用于对原始 USV 姿态数据进行预处理，并生成后续模型训练所需的**分类标签数据集**。

---

### Step 3：模型训练与预测

运行：

```text
Classification/
└── roll predict classify(25.10.2).py
```

运行前需要完成以下配置：

1. 修改 CSV 数据集路径，使其指向 **Step 2 生成的分类标签数据集**；
2. 修改代码中的模型权重保存/加载路径；
3. 根据实际运行环境配置 Python、PyTorch 和 CUDA 等相关环境。

需要修改模型权重路径的位置：

```text
第 291 行
第 300 行
第 355 行
```

将上述位置替换为本地保存的 `.pt` 模型权重路径。

---

### Step 4：泛化性测试

运行：

```text
roll classify test.py
```

用于测试模型在不同数据集上的泛化性能。

运行前需要：

1. 修改目标测试集路径；
2. **目标测试集必须是经过 Step 2 处理后的分类标签数据集**；
3. 修改模型权重路径。

需要修改模型权重路径的位置：

```text
第 281 行
```

将其替换为本地保存的 `.pt` 模型权重路径。

---

## 4. 项目流程

整体处理流程如下：

```text
原始 CSV 数据
      │
      ▼
data-pre-label.py
      │
      ▼
分类标签数据集
      │
      ├──────────────► 模型训练
      │                    │
      │                    ▼
      │                .pt 模型权重
      │                    │
      │                    ▼
      │              姿态预测 / 分类预测
      │
      └──────────────► 泛化性测试
                           │
                           ▼
                       测试结果
```

## 5. 注意事项

1. **数据路径**
   项目中的数据路径需要根据本地环境进行修改。

2. **模型权重路径**
   `.pt` 文件路径需要修改为本地实际保存位置。

3. **测试数据格式**
   泛化性测试所使用的数据必须经过 `data-pre-label.py` 处理。

4. **代码版本**
   项目中包含多个不同日期版本的代码。推荐优先使用最新版本：

   ```text
   roll predict classify(25.11.11).py
   ```

5. **依赖环境**
   建议使用与项目开发环境一致的 Python、PyTorch 和 CUDA 版本，以避免运行过程中出现兼容性问题。
